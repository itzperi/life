## 7. Source tags and the lead sheet

The website adds a Ref line to every WhatsApp message it opens (see `09-lead-tracking.md`). The first part is the source; the second is the landing page. The brief's example and the format the site actually writes:

`Ref: web/organic /industries/pharma/` (brief's example)
`Ref: organic/google.com /industries/pharma/` (format written by `/assets/site.js`)

Both mean the same thing: Source = Organic, Landing page = /industries/pharma/.

### How to log it
1. Copy the Ref line into the lead sheet the moment the chat arrives. Clients sometimes delete it, so do it before you reply.
2. Put the source part in **Source** and the page part in **Landing page**. Then group the source into one of the seven report buckets below in the **Notes** column (or a "Report source" column if you add one).
3. If there is no Ref line (calls, saved numbers, forwarded contacts), ask once: "How did you find us: Google Maps, Google search, ChatGPT or another AI app, JustDial, an ad, or a referral?" Log the answer. If unknown, log "direct".
4. Move the Status column with the WhatsApp label (New, Qualified, Quoted, Won, Lost, Job seeker). Log the date you sent `/review` and whether a review came in, in Notes.
